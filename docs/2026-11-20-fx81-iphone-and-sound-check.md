# イヌボー｜81種類の演出　iPhone 実機確認と着地音の聞き比べの手順（V01・V02）

この文書は、iPhone 17 Pro の Safari で、人が実機を使って確かめるための手順と記入表です。

私（実装を担当した Claude）は実機を操作できず、音を耳で聞くこともできません。そのため、下の表の「結果」の欄はすべて**未実施**のまま空けてあります。ブラウザ（Chromium）の自動試験の結果は、実機の結果の代わりにはなりません。

## 1. 確認版を iPhone で開く

確認版（review ビルド）は、本番の記録やランキングに書き込まない画面です。ここに、81種類の演出を1件ずつ再生する欄、着地音30種類を鳴らす欄、背景の切り替え、10秒間の計測ボタンがあります。

- **PR がマージされたあと**：GitHub Pages に `review/<コミット>/<実行番号>/` の形で公開されます。公開のホームには入口がありません（PR #27 で外しました）。そのため、GitHub Actions の「Deploy Inubo to GitHub Pages」の記録でコミットと実行番号を確かめ、公開URLの後ろに `review/<コミット>/<実行番号>/` を付けて開きます。
- **PR がマージされる前**：PR の自動検査が作る `inubo-freestyle-review` を取得し、パソコンで静的サーバー（例：`npx vite preview --mode review --host`）を立てて、同じ Wi-Fi の iPhone から開きます。

## 2. 描画の速さと反応（V01）

縦向き（402×700相当）と横向きのそれぞれで、次の順に行います。

1. 「速さ ½」を押して「速さ 1」にします。
2. 「10秒計測」を押し、すぐに「高く跳ぶ」を押して、操作パッドを左右に何度もなぞります。
3. 10秒たつと、計測の欄に結果が文字で出ます。長押しで全部を選んでコピーし、下の表に貼ります。
4. 「演出を見る」で `B-F10`・`H-A07`・`D-L10` を選び、それぞれの再生中にも計測します（最も重い演出での速さ）。

計測の欄に出る項目は次のとおりです。

| 項目 | 意味 | 目安 |
|---|---|---|
| fpsMedian | 1秒あたりの描画回数（中央値） | 60 前後 |
| p95GapMs | 描画の間隔の95パーセンタイル（ms） | 33 以内 |
| stallsOver100ms | 100ms 以上止まった回数 | 0 |
| maxLines・maxDots・maxDecals | 演出の線・点・床の印の最大数 | 記録のみ |
| inputToFrameMsMedian | なぞってから次の描画までの時間（中央値、ms） | 記録のみ |

Safari には、使用メモリを読む仕組みがありません。そのため、メモリの増え方は数値では測れません。代わりに、5分間続けて遊んだあと「やり直す」を3回押し、動きが重くならないかを目で確かめます。

確認版の球の模型は、競技の画面より軽いです。そのため、本番の競技画面でも次を確かめます。

1. 公園を縦向きと横向きで1回ずつ走ります。
2. ジャンプ中に、両方・犬だけ・人だけを切り替えながら回します。

## 3. 着地音30種類の聞き比べ（V02）

確認版の「着地音」の欄で1つ選んで「音を鳴らす」を押すと、その1音だけが鳴ります。「30種を順に」を押すと、B01 から D10 まで1.4秒おきに鳴ります。

イヤホンを使い、音量は端末の半分くらいにして聞きます。

音の作りは次のとおりです（`src/audio/sound.ts`）。段階が上がるほど、音の数・重なり・長さが増えます。どの段階も、同時に鳴る音は7つまでです。

- **B（両方）**：基準の高さは392Hzです。犬の三角波と人の正弦波が、交互に答えるように鳴ります。
- **H（人だけ）**：基準は494Hzで、やや高く軽い正弦波です。
- **D（犬だけ）**：基準は311Hzで、低めの柔らかい三角波です。長さを1.15倍にしています。

| 段階 | 音の並び | B | H | D |
|---|---|---|---|---|
| L01 | 低い単音を短く1回 | 未聴 | 未聴 | 未聴 |
| L02 | 明るい単音と短い余韻 | 未聴 | 未聴 | 未聴 |
| L03 | 2音が順に上がる | 未聴 | 未聴 | 未聴 |
| L04 | 低音と高音を同時に | 未聴 | 未聴 | 未聴 |
| L05 | 3音の短い上昇 | 未聴 | 未聴 | 未聴 |
| L06 | 中低音から高音への3音 | 未聴 | 未聴 | 未聴 |
| L07 | 4音の上昇と柔らかい和音 | 未聴 | 未聴 | 未聴 |
| L08 | 低音の拍と高音の和音を交互に | 未聴 | 未聴 | 未聴 |
| L09 | 6音の連続上昇と長めの余韻 | 未聴 | 未聴 | 未聴 |
| L10 | 7音の和音のフィナーレ | 未聴 | 未聴 | 未聴 |

聞いたら、各欄に「区別できる／隣の段階と似ている／大きすぎる／余韻が長すぎる」のどれかを書きます。あわせて、次の4つも確かめます。

| 確かめること | 結果 |
|---|---|
| 低い段階と高い段階の違いが分かる | 未聴 |
| 同じ段階で、B・H・D の違いが分かる | 未聴 |
| 急に大きな音にならない | 未聴 |
| 「消音」・端末の消音スイッチ・音量0で鳴らない | 未実施 |

自動試験で確かめたのは、次の範囲だけです。

- 30種類それぞれに音の定義があること
- 選んだ着地と音の名前が一致すること
- 同じ着地では1回しか鳴らないこと
- 同時に鳴る音が7つまでであること
- 消音・音量0では鳴らないこと

実際に聞き分けられるかどうかは、上の表に人が書き込むまで未確認です。
