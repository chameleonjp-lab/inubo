## 3. 修正の中身

### F01 空中の最高段階（`src/view/trick-fx-timeline.ts`）

原因は2つありました。1つ目は、空中の暫定の基礎点に999の上限があったことです。2つ目は、分母が「2×3600度/秒×予測滞空時間」だったことです。このため、犬だけ・人だけでは F10（難度1650）に届きませんでした。

そこで、表示専用の基礎点を次のように計算し直しました。

1. まず、物理上限の90%で回し続けた量に対して、実際にどれだけ回ったかを求めます（effort、上限1）。
2. 次に、予測滞空時間の80%までにどこまで来たかを求めます（成熟度）。
3. 基礎点は `1000 × effort × 成熟度` です。

さらに、予測滞空時間の80%に届くまでは、難度を1649で止めます。こうすると、踏切の直後に最高段階が出ることはありません。

定数は `FX_AIR_EFFORT_RATE`（0.9）と `FX_AIR_MATURE_SHARE`（0.8）の2つだけです。公式の得点、F/L と A の閾値、`scoreFreeMotion` は変えていません。

### F02 着地の位置固定（`trick-fx-engine.ts`・`trick-fx-ops-land.ts`・`trick-fx-sim.ts`）

着地Lを始めた瞬間に、使う計測点（四足・しっぽ・靴・手・肩・腰など）を一度だけ読みます。読んだ位置は、足元の基準点からの位置として接地点へ移して固定します。それ以降、着地Lの描画は固定した位置だけを読み、走っている身体を追いません。

- 読めなかった計測点は、その部品だけ描きません。原点に置いて描くことはしません。
- 接地点は、land 出来事の道・道のり・横位置・高さから求めます（`contactOfEvent`）。描画の時点の位置は使いません。
- 接地面の傾きも求めます。手すりの上なら手すりの傾き、地面なら地面の傾きです（踏切台を含みます）。床の輪や印は、この傾きに沿わせます。

### F03 高速回転（`trick-fx-sim.ts` の `FxSpinReader`・`trick-fx-engine.ts`・`scene.ts`・`free-scene.ts`）

ゲームが計算した回転の記録（`freeFlight.motion` の履歴と角速度）から、描画の時刻での角速度と累積角を求め、演出へ渡すようにしました。描画の前後の姿勢差から求める最短の回転は、自由回転の空中では使いません。

この仕組みは、競技画面と確認版の両方で使っています。古いゴーストは回転の記録を持たないので、これまでどおり姿勢差から推定します。回転の向きを作って補うことはしません。

### F04 ジャンプ間の初期化（`trick-fx-engine.ts`）

新しい jumpId の F/A が来たら、次の値を0から始めます。

- 回転の累積
- 角速度の推定
- 直前の姿勢
- 連携の印

前のジャンプの空中演出は0.2秒で消し、着地Lは寿命まで残します。`clear()` はすべての値を初期化します。

### F05 一時停止（`scene.ts`・`screens.ts`・`free-review.ts`）

`GameView` に「止まっていた時間を差し引く描画の時計」を作り、次のものをこの時計で動かすようにしました。

- 共通の粒（`Particles`）：停止中は動かず、寿命も減らず、新しく出ません。
- 足跡・旗・アイテムの回転・風の線・衝突の線

停止中は、演出の出来事の読み込みと、ゴーストの出来事の取り込みもしません。音・文字は、従来の `SoundScheduler.setPaused`・`CenterText.setPaused` で止まっています。新しく、iPhone の Safari でページを離れるとき（`pagehide`）も一時停止にしました。確認版では、停止で着地音を止め、音を順に鳴らす途中の予約も取り消します。

### F06 ゴーストの位置（`replay.ts`・`trick-fx-sim.ts`・`scene.ts`）

新しい記録の着地Lには、接地点（x・y・z・向き・傾き、mm と1/1000ラジアンに丸める）を残します。再生では、この接地点と出来事の時刻からの経過で描きます。

着地Lの計測点は、出来事の時刻の再生姿勢で読んでから固定します。接地点の無い記録（PR #29 のもの）は、出来事の時刻の再生姿勢を使います。姿勢も無ければ、着地Lは描きません。出来事の無い古い記録は、これまでどおり演出なしで再生します。

ゴーストを隠したときは演出も消し、表示を戻したら、その時刻から組み立て直します。frames・runId・保存キー・motionVersion・自己ベストの判定は変えていません。

### V04 低段階の見え方

確認版に背景の切り替えを付けました（明るい空・明るい路面・暗い路面、それに壁の前）。B・H・D の F01〜F03・A01〜A03・L01〜L03 の27件 × 4背景 = 108通りについて、演出を隠した画面との画素の差（明るさの差が30を超えた画素の数）を測りました（[v04-pixel-diff.json](evidence/fx81-followup/v04/v04-pixel-diff.json)、[背景別の画面](evidence/fx81-followup/v04/)）。

最初の計測で、次のことが分かりました。

- 光の点（F01 など）が、置かれた身体の部位そのものに隠れて、ほとんど見えませんでした。
- 青白い線（H-A02 など）は、明るい空で読みにくいことが分かりました。

そこで、次のように調整しました。

- 光の点を、身体の部位に隠れずに描き、色の輪と明るい芯で示す。
- 光の下に薄い影を敷く。
- 低い段階の濃さの下限を 0.72→0.82 に上げる（上限0.92は変えない）。
- H-A02・H-F03 を人の青にする。
- F01 と D-A02 の点を少し大きくする。
