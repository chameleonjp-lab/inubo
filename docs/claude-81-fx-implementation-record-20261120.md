## 1. 作ったもの

1回のジャンプで画面に出るのは、F・A・Lが1件ずつだけです。81件を同時に出すわけではありません。

## 2. 判断したこと

ここでは、計画書の指示に沿って決めたことを、理由と一緒に書きます。

**空中の段階は低めに出ます。** 空中での難度は、踏切のときに一度だけ決めた予測滞空時間を分母にして計算しています（R23）。このため、平地の短いジャンプで最高の速さで回し続けても、空中で届くのはおおよそ段階7までです。段階10を見せるのは、着地で確定した正式な点です。飛び始めに最高段階がいきなり出る誤りは、これで防いでいます。

**犬だけ・人だけでも最高段階に届きます。** 見た目の難度は `max(実際の技点, round(基礎点×1.65))` です（R02・R25）。画面に出る点数・加点・記録・ランキングには、これまでどおり実際の技点を使います。

**空中の軌跡は身体と一緒に動きます。** 競技画面で確かめたところ、走って前へ進んだ分が長い線として空中に残っていました。軌跡は「身体のまわりの回転」を見せるものなので、履歴の点を回転の支点と一緒に動かすように直しました。着地の演出は、床の上に残します。

**明るい背景でも見えるようにしました。** 最初は光を加算で重ねていましたが、明るい空や地面の上ではほとんど見えませんでした。そこで、通常の半透明に切り替えました。あわせて、線に沿って光の粒を並べ、その下に薄い影を敷いて、細い線でも見えるようにしています。濃さの上限は 0.72〜0.92 です。

**最高段階の連携の印はチェックしています。** B-F06・B-F10・B-L06 の「連携」の印は、実回転を伴う切替で連携数が本当に増えたときだけ出ます（R06）。ボタンの連打だけでは出ません。
