## 矛盾解消の優先順
1. ユーザー指定81個の正本と「各IDの個別描写」は一切削減しない。
2. 数字・採点値はゲーム計算を正本にする。見た目の難度の換算は見た目内部だけに閉じる。
3. B/H/Dの判定は実回転、空中での入力対象は受理済み指令で決める。ボタンの見た目だけから推測しない。
4. 旧版データの再利用を最優先にし、情報がない場合はFXを推測して誤表示しない。
5. 安全と可読性を落とさず負荷を抑える。削る場合は粒数・透明度・描画解像度で調整し、81個の個性は削らない。
