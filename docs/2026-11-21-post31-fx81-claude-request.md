## 現在の状態と目的
PR #31でF01〜F06（空中最高演出・着地位置固定・高速回転・連続ジャンプ間の初期化・停止・ゴースト再生位置）は実装され、関連する自動テストも成功しています。これらをゼロから作り直さず**回帰テストで守ってください**。

今回の目的は、実機・聴感・目視の検証を完了できる状態にすることと、確認用の道具に残る問題を直すことです。以下のQ01〜Q09をすべて扱ってください。

## 必須要件

**Q01 — iPhoneだけで使える検証導線**  
mainのGitHub Pages公開処理から「既に公開されているreview版」の正しいURLを確認し、iPhone Safariで直接開けるリンクと操作手順を日本語資料に記載。PC・ターミナルを必要としない。ホームに「自由操作の試験場」を戻さず、新たな常設公開URLを無断作成しない。

**Q02 — 低段階×背景108ケースの再現性**  
27ID×4背景について、同じ姿勢・時刻・カメラ・描画条件で演出あり／なしを比較する。壁衝突によって演出が発生しないことと、光が見えにくいことを混同しない。0差分は有効な測定か否かを分類。画像とJSONの両方にID・条件・理由を残す。

**Q03 — H-F01・D-F01の見やすさ**  
ヘルメット・鼻先の光を、明るい空や道路でも見分けられる形にする。眩しい光や大きい面で顔・HUD・障害物を覆わない。無効な比較を正した後、必要なIDだけ最小限に調整する。81種類の起点・形・向き・消え方を変えない。

**Q04 — 81件の意味まで確認できる画面**  
確認用画面で81件を1件ずつ再生し、正本の名称だけでなく「光の起点・形・向き・消え方」と照合できる説明と開始／ピーク／終了の確認操作を用意する。自動描画確認と人の目視合格を別欄に分け、未実施を合格にしない。全件の証拠一覧を提出する。

**Q05 — 着地音30種類の安全な試聴**  
B/H/D×10段階の個別再生・順番再生・聞き比べを整える。連続再生中に消音、やり直し、画面移動、一時停止を行ったら未再生のタイマーを全解除し、勝手に鳴り続けないようにする。iOSの音声開始状態も確認できるようにする。自動テストと実際の聴感を別扱いにする。

**Q06 — 100ms以上の停止の原因切り分け**  
初回起動、演出切替直後、1秒以上経過した定常状態、繰り返し切替を分けて測る。各ケースでP95、長時間停止の時刻と直前操作、描画線・点・印、入力反映時間を記録。原因が判明した範囲だけ修正し、Chromiumの参考値をiPhone実機値とみなさない。

**Q07 — Safari実機の検証と記録**  
縦402×700相当・横700×402相当、5分間、3回再挑戦、連続ジャンプ、空中の対象即時切替、一時停止、別アプリへ切替・復帰、ゴースト、長い技名を確認できる手順と記録画面。測定結果や音のメモはユーザーが1タップでコピー可能にする。外部送信は禁止。

**Q08 — 既存機能の回帰**  
PR #31のF01〜F06、81ID、L30、150技名、切替連携加点、ランキング・Supabase・自己ベスト・保存キー・ルール版・総合結果30段階・称号60種・旧再生・ホーム削除5項目を維持。新しいテストをskipして済ませない。

**Q09 — 確認版のルール表記を最新に**  
実際の\`FREE_RULES_VERSION\`は\`rules-freestyle-2\`ですが、\`vite.config.ts\`の\`review-info.json\`と\`scripts/check-review-build.mjs\`は古い\`rules-freestyle-1\`を扱っています。ゲームのルール版を変えず、確認版のメタ情報と検証処理を現行の値と一致させるテストを追加してください。
