# 実機受入の記録（P09）

[実装計画書](implementation-plan.md)の P09 で使う記録表です。iPhone 17 Pro の Safari で、同じ人が同じ配置で測ります。ここに書くのは**実機で見聞きした結果だけ**です。ブラウザ上の自動検査の結果は[自動再生の記録](autoplay-report.md)と試験（`npm test`・`npm run test:e2e`）に分けて残します。

2026年11月7日の時点で、下の実機の欄はすべて未実施です。私（実装を担当した Claude）は実機を操作できないため、この表は空欄のまま用意しました。

**自動操縦での参考値と、未決の点。** 自動操縦では3区間すべてでウィペットが最も速く、コーギーが最も遅くなりました（[自動再生の記録](autoplay-report.md)）。自動操縦は横移動を急がない手順なので、コーギーの「目標の横位置に早く届く」性能が生きる場面（急カーブの内側の細い道、商店街の狭い近道、障害物の直前での回避）を使っていません。実機で同じ人が測り、それでも「どの条件でも同じ犬だけが勝つ」なら、計画書どおり原因の工程（P02 の横移動、P05 のコース配置）へ戻します。
