# イヌボー 空中技の描写仕様

公園と練習広場の自由操作が対象です。[自由操作のスコア表](freestyle-score-table.md)の点数で演出の強さを決め、[技名一覧](https://github.com/chameleonjp-lab/inubo/pull/22)の犬・人・両方の技に共通で適用します。操作確認版にも、同じ回転と得点を与えると同じ色・形・時間で表示されます。

着地の瞬間を一番派手にします。跳んでいる間は回っている本人や犬の動きを見せ、着地すると足元に光が広がり、その上に技名が出ます。走行は演出中も続きます。

## 空中では、実際の回転を見せる

| 回った対象 | 光の出る場所と見え方 |
| --- | --- |
| 犬 | 前足の外側に短い琥珀色の点線を出す。点が連なって、肉球で円を描いたように見える |
| 人 | 肩の外側に細い青緑の実線を出す。肩の大きな動きが弧になって残る |
| 両方 | 琥珀の点線と青緑の実線を同時に出す。重なる場所でも点線と実線を見分けられる |

線は体の現在位置と過去の位置を結びます。ゲーム内の時間で12ミリ秒ごとの位置を取り、最長140ミリ秒分、1体につき最大12点を使います。点を追加するのは、その体の実際の回転速度が毎秒18度以上の間です。先端を明るく、古い側を細く薄くします。指を離しても実際に回転している間は線が続きます。逆に回したときは、直前の線が消えながら新しい向きに線が伸びます。回転が毎秒18度を下回ったときと着地したときは、新しく線を出さず140ミリ秒以内に消します。

1方向の技は、宙返りなら上下の弧、スピンなら周囲を回る輪、横転なら進行方向を軸にした弧として見えます。左右・前後の違いは線が伸びる向きに表れます。2方向以上では同じ線が向きを変えていくため、連続した動きが読めます。回転数に合わせて決まった形を再生せず、実際に通った軌跡を使います。

## 着地は点数で5段階に分ける

点数は1回の技そのものの点数です。区間の加点制限とは別に段階を決めます。粒の数は標準表示で1回に追加する上限です。輪は着地点に沿って低く広がり、足場や手すりから浮いて見えないようにします。

| 技の点数 | 着地直後に見える動き | 技名と点数の表示 |
| --- | --- | --- |
| 1〜199 | 砂の粒6個が足元で小さく散り、180ミリ秒で消える | 白文字と濃い縁。1.0秒 |
| 200〜399 | 水色の輪1本が足元から半径0.9mまで広がり、粒10個とともに260ミリ秒で消える | 水色の文字。下に水色の細い線を1本。1.2秒 |
| 400〜649 | 青い輪2本が70ミリ秒差で広がる。二つ目は半径1.3m、粒は計16個。着地から380ミリ秒で消える | 白に近い青の文字。濃い縁と青い光。1.4秒 |
| 650〜849 | 金の輪2本が90ミリ秒差で広がる。二つ目は半径1.7m、粒は計24個。金色の足跡が4つ残り、650ミリ秒以内に消える | 金の文字。表示開始から160ミリ秒で細い光が文字の下を左から右へ1回通る。1.7秒 |
| 850〜1,000 | 白金・金・紫の輪3本が70ミリ秒ずつずれて広がる。最後は半径2.1m、粒は計32個。粒のうち最大8個を短い星形にして外へ散らし、650ミリ秒以内に消える | 白金の文字、紫の縁、金の光。技名の上下に細い飾り線。2.0秒 |

1,000点のときだけ、最上段の点数表示に「満点」を添えます。点数と技名の読みやすさを保つため、輪や粒は路面付近に集めて、粒の高さを着地点から0.6m以内に収めます。画面全体の白い点滅、カメラの追加揺れ、ズーム、スロー再生は使いません。

技が成立した着地ごとに一度だけ再生します。公園で区間の加点があり、練習で技点が付くときは技名の下に「＋132」のように数字を出します。公園で区間が採点済みの場合は「区間採点済み」、採点区間の外では「加点なし」と表示します。0点で技が成立しない着地は砂だけです。飛行中の衝突や落下で技が成立しなかったときは、対応する衝突・落下の表示を使います。

## 着地で鳴る音

| 技の点数 | 効果音 |
| --- | --- |
| 1〜199 | 短くやわらかい一音 |
| 200〜399 | 鈴のような二音が上がる |
| 400〜649 | 明るい三音が順に上がる |
| 650〜849 | 二音から始まり、三つの音が重なる |
| 850〜1,000 | 低い一音から駆け上がり、高い和音で締める。約0.5秒 |

派手さは音色・音の数・重なりで出し、効果音を強く鳴らすことで段階を分けません。音量と消音の設定を使い、技1回につき効果音を一度だけ再生します。区間が採点済みでも、成立した技の段階の音が鳴ります。操作確認版は、着地後も結果を読み返せるようその場に表示し、画面上で消音できます。

## 走行中の見やすさ

- 技名は画面上部の走行表示と操作ボタンに重ならない位置へ置き、点数を一段下に表示します。技名は省略せず、助詞や「・」などの区切りで折り返します。技名の文字サイズの下限は16 CSSピクセル、点数は14 CSSピクセルです。縦402×700と横700×402で、最長の技名と点数が端・セーフエリアから少なくとも8 CSSピクセル内側に収まることを確認します。
- 同時に画面に出す技名は最新の1件です。着地の前の回転線が残っている場合でも、次の動きと見分けられるよう古い線は140ミリ秒以内に消し、着地の輪と粒は新しい技が成立したところで入れ替えます。衝突や落下が同時に起きた場合は、衝突や落下の表示を優先します。
- 端末で動きを減らす設定を選んだ場合は、光が流れる動き、線の残り、飛ぶ粒を止めます。足元は広がらない輪1本を180ミリ秒表示し、技名と点数は段階に応じた文字色と縁で見分けます。音の有無で演出の内容が分からなくなる作りにはしません。
- 1回のジャンプにつき最大32粒、輪は最大3本、地上の足跡は最大4つです。必要な描画部品は使い回し、長時間のプレーで増え続けないようにします。ゲームを一時停止した間は演出時間も止め、やり直し・ホーム復帰で前の演出を消します。

## 実装後に確認する場面

| 確認場面 | 合格条件 |
| --- | --- |
| 空中の対象と向き | 犬だけ、人だけ、両方の3ケースで線が正しい位置から出る。指を離した後の慣性と切り返しに追従し、線が着地後に残り続けない |
| 段階の切り替え | 0/1、199/200、399/400、649/650、849/850点の境目と1,000点を試し、表の色・輪・表示時間・満点表示に一致する |
| 連続する出来事 | 着地の追加点、採点済み、区間外、壁への衝突、手すり着地、一時停止後の再開をそれぞれ確認し、技名や加点表示が二重に出ない |
| 縦横の見え方 | iPhone 17 ProのSafariで縦横を確認する。最長の技名が読め、着地直後も進行方向とスワイプを続ける場所が見える。動きを減らす設定も確認する |
| 負荷 | 同じコース・同じ入力を使い、上位2段階の着地を30回再生する。通常走行からのフレーム時間の増加は、遅い側5%の境目で4ミリ秒以内を目標とする。演出用の描画部品数とイベント数が着地のたびに積み上がらない |
