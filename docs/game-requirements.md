# 犬のスケボー（inubo）要件仕様書

2026年11月7日・初版。80件すべてについて推奨案の採用が決まった。本書をゲームの仕様、[実装計画書](implementation-plan.md)を作業と検収の手順とする。

## 1. どんなゲームか

人が犬の背に乗り、犬そのものをスケートボードに見立てて街を滑る。公園の階段なら、まっすぐ跳ぶと短い。隣の手すりは少し遠いが、そこから飛び降りて犬を横に回し、きれいに着地すれば技点が入る。初めて遊ぶ人は脇の坂を通っても完走できる。

1回の走行から、**総合スコアの自己最高**と**完走タイムの自己最速**を別々に残す。総合では技の難しさと速さを競い、最速ではゴールまでの時間を競う。基本はスマホ縦持ち。横持ちでも同じコース・指の方向・採点で遊べる。

**仕様の読み方。** 末尾の「採用した80件」は、元の番号・選択記号・採用した文言を保持する。60〜90秒は最初のコースの目標タイムで、制限時間ではない。公園の基準秒、円の縦横比、着地の角度、横移動の指数など、原案で試作値としたものは初期値として採用する。公開記録を取り始めた後で採点やコースを変える場合は、旧版の記録を保存し、新しい版に分ける。

## 2. スタートから再挑戦まで

| 場面 | 遊ぶ人に見えるものと、できること |
|---|---|
| ホーム・選択 | コース、犬種、服・ヘルメットの色、練習、遊び方、設定を選べる。3コース・3犬種を最初から選べる。公開順位へ参加したい人はスタート前に任意で名前を入れる。 |
| 練習広場 | 時間を競わず、左右移動→ジャンプ→犬だけの円→体ごとの直線→複合技の順に手本と自分の軌跡を見比べる。途中で本番へ進める。練習の記録は競技記録と分ける。 |
| 走行 | 「3・2・1」の後、「スタート」と自動発進を同じ瞬間にする。経過タイム、確定した技点、ゴールまでの進み具合を表示する。視点は犬の少し後ろ・上。カーブには路肩の矢印を置き、回転中も視点は道の先を向く。 |
| 一時停止・復帰 | 手動停止、画面の縦横変更、ブラウザが裏に回ったときは景色を覆う。時計・効果の残り・回転・動く障害・手本の走り・音を一緒に停止。押したままの指を解放し、「再開」から同じ場面へ戻る。画面に戻っただけでは発進しない。 |
| ゴール・結果 | 総合点を大きく、その下に完走タイム・タイム点・技点。更新した記録だけを祝い、いちばん惜しかった区間と次に試せる操作を最大1件示す。同じ犬・コースで1操作で再挑戦できる。 |

## 3. 地上・空中・手すりの操作

| 入力と場面 | 成立条件と結果 |
|---|---|
| 地上の左右 | 払った幅で目標の横位置を決め、そこまでなめらかに動く。同じ指幅なら犬種によらず同じ位置を狙える。地上の下払いには走行操作を割り当てない。 |
| 前ジャンプ | 縦・横どちらの画面でも「前」は画面の上。必要距離を払った時点で1回跳ぶ。踏み切った指の残りの動きは使い切った扱いとし、空中技には新しいタッチを使う。平地の高さは共通、踏切台では高く跳ぶ。 |
| 犬だけの回転 | 円が閉じたら、縦長なら鼻が上下を通る前後の一周、横長・真円なら鼻としっぽを結ぶ軸の横転。人の胸と視線を前に保つ。時計回りと反時計回りで回転方向を反転する。初期の縦判定は軌跡の高さが幅の1.25倍以上。 |
| 体ごとの回転 | 空中で直線を引いて離す。上＝前宙、下＝後宙、左・右＝その側への水平のひねり。斜め4方向は前後の宙返りと左右のひねりの組み合わせ。全周を45度ずつの8方向に分ける。技の回転で進む道が急に変わらないようにする。 |
| 円＋直線 | 2本指の軌跡が時間的に重なれば、どちらを先に認識しても同じ複合技にする。片手なら円を閉じ、そのまま同じ指で犬の回転が終わる前に直線を引いて離す。両方式で技名・配点・回転枠は同じ。 |
| 判定中の線 | 指ごとに薄い跡を出す。閉じかけの円の一部分を直線として先取りしない。閉じたところで円を切り出し、その後の線だけを別に読む。短いタップ・閉じていない曲線は技にしない。同じ軌跡を二度数えない。 |
| 手すり | 上から下りながら足元を重ねて乗ると滑る。正面・側面にぶつかると前進は停止。滑走中は前スワイプで跳び降りられる。末端から自然に降りてもよい。 |

ひと跳びで使えるのは最大2枠。犬1周または体ごと1周で1枠。斜めの宙返り＋ひねりは合わせて1枠なので、犬＋斜めでも2枠に収まる。犬だけを2周することもできる。2本の指が重なっている間は先に認識した技を仮置きし、相方が成立した瞬間に両方の回転を同時に始める。相方が取り消されたり片方だけ有効なまま離したりした場合、空中なら成立済みの単独技を一度だけ開始する。着地までに開始できなかった候補は破棄する。片手は円を閉じた時から犬が回り、入力した線を犬の回転終了より前に離せば複合、終了と同時か後なら複合加点は付かない。着地後の指や、前の走行の指は次のジャンプに引き継がない。

## 4. 3つのコースと3種の犬

| コース | 走り方の違い | 設計で確かめること |
|---|---|---|
| 公園 | 短い平道と長い手すり道が合流する。階段中央・横の手すり・脇の坂を見渡せる。 | 60〜90秒を目安に、採点区間は12か所。技を使わず全犬種で完走でき、寄り道で総合点が逆転する。 |
| 商店街 | カーブ、階段、狭い近道を組み合わせる。壁に当たったらその場で横か上へ逃げられる。 | 先が見える位置に標識を置き、加速中でも障害物を突き抜けない。 |
| 川沿い | 長い直線と長い手すりで、直線型の犬と複合技の両方に見せ場を作る。 | 走路外への落下、復帰、手すりへの乗り直しを試せる。 |

上りは緩やかに減速、下りは緩やかに加速する。道の曲がりには自動で沿い、内側の実走距離を短く、外側を広くする。階段、壁、柵の高さは見た目と接触判定をそろえる。低い柵には足跡帯を付け、正面で停止してもその場から跳び越せるようにする。高い壁には坂の印、踏切台と横の抜け道を設ける。骨形ゲートは合図音とランプの後に地面から上がり、走行開始を起点に毎回同じ時刻に動く。

正面衝突したら前進速度は0。停止中も横移動とジャンプは有効で、前が開けば自動発進する。落下時は直前の安全な復帰地点へ戻り、その間も走行時計と効果時間は進む。確定済みの点・使用済みの物・一度得点した区間と手すりは保持する。未確定の回転・手すり点と連続成功数は解消する。新しい走行を始めると1走分の状態だけを初期化する。

| 犬種 | 直線の最高速 | 目標の横位置に届く速さ |
|---|---:|---:|
| 柴犬 | 100 | 100 |
| コーギー | 93 | 115 |
| ウィペット | 107 | 85 |

数値は柴犬を100としたゲーム内の指数。ジャンプ、回転、接触判定の大きさ、同じ技の配点は共通。人が犬の背に乗り、平地・上りは足で蹴り、下りは犬が足をたたんで滑る。着地に備えたら四肢を広げる。乗り手は1人で服とヘルメットを着せ替える。犬種×コースで完走スタンプを集める。同じ組を走り直しても重複しない。

## 5. アイテムと時間

| 触れたもの | 効果 | 重なり・再取得 |
|---|---|---|
| ドッグフード | 袋と犬が同じ高さで触れると、その犬・路面での通常速度の1.25倍が5秒間続く。空中の袋も取れる。 | 別の袋で残りを5秒に戻す。倍率は積み増さない。 |
| 犬の糞 | 地面に接した足元が重なると2秒間、速度が通常の60％になる。空中なら越えられる。 | 別の糞を踏むと残り2秒に戻る。フードの効果中は両方を掛けて75％にする。 |
| 骨形の道しるべ | 次の分岐で技を狙える道に足跡が浮かぶ。 | 合流したら案内を閉じる。案内自体のスコアは0。 |

効果の開始時刻を含み、終了時刻ちょうどに元に戻す。壁で止まっても残り時間は減り、実速度は0。一時停止中は両方の残り時間が止まる。競技の配置はコースの版ごとに固定し、同じ走行で拾った物・踏んだ糞は復帰しても戻さない。糞は出口の見える直線に置き、跳ぶ道と横によける道を残す。

## 6. 採点と確定する順番

**総合点＝タイム点（0〜5,000）＋技点（0〜5,000）。上限は10,000点。** 時計はスタート合図から、犬種共通の足元中心がゴール線を初めて越えるまで。表示と順位には同じ0.01秒単位の整数を使う。コースごとに満点タイムと0点タイムを固定し、その間を均等に配点する。

| 採点対象 | 条件・計算 |
|---|---|
| タイム点 | 満点・0点・記録を同じ0.01秒単位にする。5,000 ×（0点タイム－記録）÷（0点タイム－満点タイム）を0〜5,000に収め、整数に四捨五入。公園の初期値は60.00秒／110.00秒。ほかの2コースは実測して公開前に同じ形式で固定する。 |
| 技の基礎点 | 犬だけ100、体ごとの上下左右150、体ごとの斜め200。2枠を使えば各点を1回ずつ足す。犬と体の複合成立時だけ100点を1回加える。 |
| 着地 | 予定の回転の残り角度と、着地面に対する足の傾きを見る。すべて10度以内なら「ぴたり」で技の小計を1.2倍、すべて30度以内なら1倍、それ以外はそのジャンプの点が0。斜め技はひねりも検査する。以前に確定した点は残る。 |
| 手すり点 | 滑った距離の整数メートル×10点、1本100点まで。上からうまく乗った時点で直前の空中技を確定。手すり自体の点は降りた先で無事に接地したときに確定し、通常着地でも満額。手すり点に着地倍率は掛けない。 |
| 区間と連続成功 | 1区間で最初に成功した**技を含むジャンプ1回分**を採点する。普通に跳ぶだけでは機会を消費しない。まだ採点していない区間を進行順に3区間連続で成功すれば100点、次の3区間は0から数える。失敗・衝突・区間の通過漏れ・落下で連続数を戻す。 |
| ゴール | 接触した時刻の順に処理。同じ瞬間なら着地・手すり点・連続点を確定してからゴールとする。先にゴールしたときは、その後の着地を採点しない。未完走には完走順位を付けない。 |

公園での検算例。同じ犬で最短の道を76.00秒・技点1,200で走ると **3,400＋1,200＝4,600点**。手すりの道を80.00秒・技点1,800で走ると **3,000＋1,800＝4,800点**。差の600点は、横転＋右ひねりの「ぴたり」420点、8mの手すり80点、連続100点で作れる。最速は1走目、総合の自己最高は2走目として残る。

**境界で迷ったときの扱い。** 着地した足元中心が属する区間に、ジャンプ全体を1回だけ割り当てる。開始線は含み、終了線は次の区間に含める。分岐では選んだ道上の採点区間だけを順に数える。共通A→左右のどちらかBまたはC→共通Dなら、A・B・Dの成功で連続100点。Bに入って技を決めずDへ行けば連続加点は0。同じ分岐位置にあるBとCは同じ採点機会として管理し、落下後に反対側を通っても取り直せない。

着地とゴールの前後は、表示用に丸める前の走行時刻で比べる。完走した瞬間にのみ、記録を最も近い0.01秒に四捨五入する（0.005秒ちょうどは上へ）。たとえば76.002秒のゴール後に76.004秒で着地した技は0点。両方が76.00秒と表示されても順番は変えない。角度は予定した方向への残りを使い、回し始めの0度を1周終了と見なさない。

## 7. 記録、練習、結果の共有

コース・コースの版・ルールの版を組にして、参加者別の総合自己最高（降順）と自己最速（昇順）を別々に集計する。それぞれに達成時の犬種を添える。同点・同タイムは同順位。1位が2人なら次は3位。半透明で見せる「自分の最速の走り」は表示を切り替えられ、当たり判定・取得・採点に関与しない。別の犬で最速を更新したら、記録と一緒にその犬の走りを採用する。同じタイムなら先に保存済みの最速走行を使う。コースだけを変更した場合も、古い走りは新しい道に重ねない。

コースごとに寄り道課題を1つ用意し、達成はスタンプで祝う。総合点の式は同じ。結果の「Xでシェア」には犬種・コース・完走タイム・総合点・確認済みの正式URLを入れる。投稿画面を開き、投稿は遊んだ人が決める。画面を開けないときは同じ文をコピーできるようにする。

**公開ランキングと実験場に接続する段階。** ホームで名前は任意。空欄でも全犬種・全コース・練習・端末内記録を使える。公開記録はスタート時の有効な名前に限り、終了後の追加入力で過去走行を公開しない。同名の人は混ぜず、同じ走行の再送は1回分として扱う。公開・登録が認められた後は、ホームと結果の「ランキング」から実在する詳細ページへつなぎ、結果は同じ条件の上位30人を表示する。通信待ち・記録なし・失敗・再試行を区別する。正式URL・各順位表の登録先・公開開始は実装時に確認する。

空欄開始・練習では、個人ランキング用の開始や完走を送信・送信待ち保存しない。順位表の閲覧と端末内の成績は使える。参加走行では1件の確定した完走を2種類の順位の集計元にし、回線が途切れても総合とタイムが別の走行として登録されないようにする。上位30人の境目が同順位の場合も表示人数は最大30人。同じ順位内の表示順は両画面でそろえる。

## 8. すべてのアクションに付ける演出

同時に起きたときは「停止・失敗」「着地・技」「アイテム」の順に中央の短い文字を優先し、他の情報は足元の印・結果に残す。音のオン／オフ、音量、揺れ、光の量は別々に保存する。消音・弱い演出でも成功と失敗を区別できるようにする。

| 番号・場面 | 見せるもの | 聞こえる音 |
|---|---|---|
| E01・犬・コースを選ぶ／決定／戻る | 選んだ犬がしっぽを振る。決定で足跡に丸、戻ると印が引く | 選択は軽い一音、決定は上がる二音、戻るときは下がる一音 |
| E02・開始を待つ／発進 | 「3・2・1」で犬が少しかがみ、「スタート」で足元に砂が跳ねる | 短い拍を3回、発進で明るい合図 |
| E03・通常走行／直線の最高速 | 足が路面を蹴り、普段は短い足跡。最高速では耳や服が強くなびく | 速さに合わせて足音の間隔と風音が変わる |
| E04・左右移動／カーブ | 横移動では体重を移し、カーブでは内側へ体を傾けて外の足に砂が舞う | 小さな踏み替え音、強いカーブで短いすれ音 |
| E05・上り坂／下り坂 | 上りは人が前かがみ、下りは犬が足をたたんで風の線が伸びる | 上りは地面を蹴る音、下りは連続する風切り音 |
| E06・ジャンプ／踏切台からの大ジャンプ | 犬の脚が縮んで伸び、地面に蹴り跡が出る。踏切台では跡を太くし、影が大きく離れる | 短い踏切音。高いジャンプは上がる風音を重ねる |
| E07・犬だけの縦回転／横転／逆回転 | 「犬・縦」「犬・横」と出し、鼻先または足先の線が回転面と向きをなぞる | 縦・横で音色を変え、逆向きは音の順を反転 |
| E08・人と犬の体ごとの回転／斜めの技 | 払った方向の小さな矢印と、肩を通る軌跡。斜めは宙返りとひねりの両方が見える | 回転中は風を巻く音、斜めは二つ目の短い音を添える |
| E09・複合入力／複合技の着地成功 | 入力がそろったら二つの軌跡を重ねる。成功した着地で足跡と技名・獲得点を出す | 入力は短い予告音、成功で二音が重なる |
| E10・入力が短い／技が未成立 | 指の線が静かに薄れる。練習では「もう少し大きく円を」と手本を出す | 練習だけ控えめな一音。本番では走行音を優先 |
| E11・壁・柵・階段を跳び越す／坂で迂回 | 越えた縁に足跡が弾み、人が膝をゆるめる。迂回路は曲がった先で道標が揺れる | 通過は軽い「トン」。迂回は路面に合った足音 |
| E12・手すりに乗る／滑る／離れる | 乗った所に光点、滑る間は接点から細かい光、出口で線が途切れる。無事に降りたら距離と点を表示 | 乗ると一音、滑走音は接触中だけ、離れると止まり、加点で短い確認音 |
| E13・通常着地／ぴたりと着地 | 通常は着地点に小さな砂の輪。「ぴたり」はそろった四つの足跡と加点 | 通常は柔らかい一音、「ぴたり」は澄んだ二音 |
| E14・着地失敗／姿勢を立て直す | 犬が踏み直し、人が腕でバランスを取る。「回転不足」を着地点の脇に出す。復帰したら姿勢が戻る | 鈍い着地音と短い立て直し音 |

## 10. ゲームとして受け入れる条件

1. iPhone 17 ProのSafariで縦・横とも、通常ジャンプ、犬のみの縦横、体ごとの8方向、片手・両手の複合技を実際に決められる。踏切の指が勝手に空中技を出さない。
2. 全3犬種で全3コースを完走できる。低い柵からの脱出、高い壁の踏切台、手すりの上と側面、加速・減速中の衝突を区別する。同じ人が3犬種で直線・急カーブ・手すり分岐を反復して差を記録する。
3. 採点例の二走を再現し、落下・手すり再通過・一時停止・ゴールをまたいでも1走に同じ点が二度入らない。2種類の記録が別々に残る。
4. 縦の表示範囲が402×700の条件と横向きで、犬・次の障害物・着地点・停止ボタンが見える。消音と光を弱めた設定で、着地、複合成功、停止、減速を見分けられる。実機で行った項目には検証日と対象版を記録する。
