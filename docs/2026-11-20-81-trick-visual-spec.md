# イヌボー：81種類のトリック演出・改訂要件仕様（2026-11-20）

> この文書は「5×5×4＝100通り」という以前の解釈を取り消し、**27種類×3操作対象＝81種類**という依頼を正式な要件にする。旧100通りの実装が残っている間は「未実装」。本書の名称と動きをそのまま置き換えの基準にする。

## 1. 個数の定義と採用理由

各操作対象に対して、**派手さ（空中の全体強調）10段階**、**空中の軌跡7段階**、**着地時の演出10段階**を別々に作り、27種類とする。対象は「両方（B）」「人のみ（H）」「犬のみ（D）」の3種類なので合計81種類。これは10×7×10の組合せ数ではない。個々の演出には固有の形・起点・動き・終了条件を与える。単純な色変更だけで別項目とは数えない。

## 2. 適用条件と画面・音の共通要件

- **派手さ**は空中の雰囲気と強調効果。実得点に応じて10段階、閾値は1、80、160、260、400、550、700、950、1250、1650点。開始直後は最低段階。推定点が変動しても、同じジャンプの中で段階を下げない。10段階目は高難度の成功が確認できる場合だけ。
- **空中の軌跡**は回転した対象の部位が通った道を示す。7段階の閾値は1、160、400、700、950、1250、1650点。画面に描く位置は実際の手足、肩、頭、鼻、しっぽの座標を元にし、方向・速度・回転軸が変われば軌跡の曲がり方も変える。動作を偽装するだけの演出は不可。
- **着地時の演出**は着地確定時の最終技得点により10段階で選び、派手さと同じ得点閾値を使う。着地成功の通知ごとに一度だけ発生する。区間が採点済みでも技の難しさで演出を選び、点数表示は「区間採点済み」にする。衝突・失敗は成功演出に置き換えない。
- 空中で操作対象を切り替えた瞬間、**次のスワイプから**その対象の演出に切り替える。切替直後に残る古い軌跡は0.2〜0.4秒でフェードさせ、過去の動きの記録として残してよい。連携得点は従来の実回転判定を維持し、ボタン連打だけで加点しない。
- 着地演出の対象分類は犬と人の実回転を使う。両方とも有効回転があればB、犬だけならD、人だけならH。切替の結果両者が動いた場合はBにし、追加ボーナスは独立して表示。途中の操作対象選択だけで着地の分類を決めない。
- 小さいiPhone画面（縦402×700、横700×402）で技名・点数・操作ボタンが読めること。顔・足・障害物や画面中央の重要な情報を光で隠さない。強いストロボ点滅・画面の真っ白化・強制スロー・操作禁止時間を使わない。
- 光を弱くする設定と「動きを減らす」端末設定に対応し、光の量・残像・粒数を下げる。音量・消音に従い、音がない場合も形と文字で難度が分かる。音は段階に合わせて調子と重ね方を変えるが、同時発音上限を守り、連打で重ならない。
- 結果総合点0〜10,000点に対する既存の30段階の結果演出・60称号と混同しない。ここでの81種類は**ジャンプ中と着地時**だけ。採点・ランキング・自己ベスト・再生データの既存記録は消さない。

## 4. 実装と敵対的検証の確認項目

1. 81個のIDが重複せず、B/H/Dの各F10・A7・L10が揃うことを自動テストで検証。旧100通りの選定処理が混ざらないことも検証する。
2. 同一の回転履歴と得点ならリプレイ・本番・操作確認版で同じ演出ID。演出の乱数や描画速度は採点に影響させない。途中で対象を切り替える場合でも軌跡を誤った対象へ付けない。
3. 10段階と7段階すべての境界値（境界の前・ちょうど・後）で正しい段階が選ばれること。得点0・満点を超える連携得点・区間採点済みも含む。
4. 光・粒・音の負荷上限を定め、低負荷機能を使う。目安として空中描画は90msごと、着地追加粒は最大72、既存の全粒子600を超えない。数値は実機で落ちる場合に絞る。
5. 連続ジャンプ、途中衝突、空中での停止・再開、対象切替・同時指操作、画面縦横回転により演出が残り続けないこと。設定変更やリプレイで採点が変わらないこと。

## 5. ホーム整理（同じ変更に含める）

ホームから「練習広場」「乗り手の色選択（服・ヘルメット）」「従来ルールで走る」「スタンプ帳」「自由操作の試験場」を削除。保存済みの服・ヘルメット色、練習進捗、旧ルールの成績、スタンプ、順位データの削除・書換えは禁止。検査専用経路の機能は維持し、公開ホームに入口を出さない。ホームは犬の選択／スタート／遊び方／設定／名前欄（必要な環境のみ）／ランキング（接続時）／Xシェア／現行の記録に整理する。

## 6. 2026-11-20 敵対的レビューと対策

**誤読リスク**：81種類は3つの項目を掛け算した数ではない。ID合計をテストする。 **描写の混同**：対象ごとに追跡する部位を固定し、犬のみ時に人側の回転線を出さない。 **低得点のまま派手すぎる**：段階閾値を明示し、最高段階は高得点だけ。 **遊びやすさの低下**：技名と足元の視認性を優先し、減光・動作低減を必須にする。 **旧データの損失**：ホーム入口と記録の保存処理を分離し、データ削除は行わない。
