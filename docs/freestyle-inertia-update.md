# イヌボー 慣性を使う自由操作への変更

2026年11月17日。ユーザーの「慣性で回っている方がよい」という選択を反映する。[自由操作の設計](freestyle-control-design.md)・[実装計画](freestyle-implementation-plan.md)の「指離しで姿勢を保持する」初期案を置き換える。操作確認版で慣性を試せる。競技への組み込みと実機での確認は後続工程とする。

## 1. 操作の決定事項

- スワイプで回転の勢いを加え、指を離した後も回り続ける。同じ向きへ払えば加速し、逆向きへ払えば減速する。逆入力が十分なら停止を経て逆回転する。
- 指を置き直すだけ、対象を切り替えるだけでは、既存の勢いを消さない。無入力と停止操作を同じにしない。回転量を360°等へ自動で丸めない。
- 慣性で実際に回った動きも、着地までの履歴と得点に含める。指の軌跡の長さや入力回数だけを点にしない。
- 停止・再開では姿勢と回転速度を保存し、停止中の実時間は進めない。やり直し・別試行では新しい状態を作る。床や走行面に着いた時点で採点する。着地姿勢による失敗や減点は扱わない。

## 2. 回転の計算

2026年11月19日。空中の感度と回転速度を最初の調整前の5倍に調整する。対象は犬だけ・人だけ・一緒の自由操作で、公園・練習広場・操作確認版に共通する。

既存の仮想球から求めた軸と角度を回転速度への加算に使う。角度ベクトルΔφ（ラジアン）に対して `Δω=20×Δφ`（ラジアン毎秒）を加える。細分した同じ入力区間の加算合計は同じにし、イベント件数や描画フレーム数を倍率にしない。短時間で払うほど減衰を受ける時間が少なくなり、強い勢いが残る。

状態は世界座標の `omegaCommon / omegaDog / omegaRider` を持つ。「一緒」はcommon、「犬」「人」は各対象へ加算する。各成分のベクトル長上限は3,600°/秒とする。共通と個別が重なる場合の合成速度は別に扱い、対象変更時に個別の勢いを消して見かけをそろえない。自由操作の走行では20ミリ秒ごとに姿勢を記録し、速く回っても再生で逆向きに補間されないようにする。

無入力時の回転速度は0.8秒で半分になるよう `ω(t)=ω0×exp(-λt), λ=ln(2)/0.8` とする。角度は `Δθ=ω0×(1-exp(-λΔt))/λ` で進める。犬と人の世界姿勢にはcommonと各対象の合成速度を使い、共通支点を回る位置の変化にはcommonを使う。逆スワイプは現在の速度へ逆向きの量を加え、指示された停止角へ飛ばさない。

入力時刻の前まで慣性運動を進め、その時刻に速度を変更し、次の入力・接触まで進める。外側の5ミリ秒刻みを維持し、内部を入力や接触の時刻で分ける。同じ入力ログを違う描画間隔で再生しても同じ結果にする。

接地したら空中の運動を終え、地上走行へ戻る。壁やゲートに当たったときは障害物への衝突として処理する。

## 3. 旧案から変更する実装契約

G01の入力は姿勢ではなく回転速度を変える命令を送る。G02の `FreePoseState` に3種類の回転速度を追加し、`advanceFreeMotion(state, untilUs, inputs)` で時間に沿って進める。`AppliedRotation` は慣性を含む実際の時間区間 `startUs < endUs` の姿勢・位置・回転支点を記録する。

入力が届いた時刻そのものに、姿勢を空間経路に沿って瞬間移動する旧案は使用しない。同じ有効時刻の複数入力はseq順に速度へ加算するが、その間に時間が進まなければ姿勢・保持時間・得点を増やさない。新しい速度から先の運動と接触を計算する。

G03は慣性運動中の最初の接地で履歴を閉じ、接地より後の入力や回転を空中点へ足さない。G04は、入力中も指離し後も実際に回転した角度を方向ごとに集計する。[自由操作のスコア表](freestyle-score-table.md)に従って着地時に得点を決める。G05の見本も、勢いを加える・逆入力で抑える入力列として同じエンジンへ通す。

G06の中断と再生には回転速度を含める。古い保持型の実機確認結果を流用せず、G08のinteraction確認版で、離した後の継続・減速・停止・逆転を先に確かめる。既存の新旧記録分離と本番通信をしない確認版の条件は引き継ぐ。

## 4. 実装時の合格条件

- [ ] 速度360°/秒から無入力で0.8秒進めると180°/秒になること、角度が約207.75°進むことを計算試験で確認する。速度0・入力0なら自動整列や勝手な回転がないことも確かめる。
- [ ] 逆入力で正の速度→0→負の速度へ連続して変わること、触れる／離す／対象変更だけでは速度が消えないことを確認する。
- [ ] 同じ軌跡を細かく分けても速度加算の合計が変わらず、同じ有効時刻付きログを8／16／33ミリ秒の描画間隔で再生して姿勢・速度・着地・点が一致することを確認する。
- [ ] 慣性回転の途中で壁・床・レールに当たる例、同時刻の入力と接地、停止中の時計、再開、別試行への持越し0件を試す。
- [ ] iPhoneで弱い払い・強い払い、離した後の回転、逆入力による回転方向の切り替えを確認する。係数の変更は実機記録と入力ログを付け、コードの試験と操作感の合格を分けて記録する。
