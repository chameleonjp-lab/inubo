## 検査結果

変更前の254件と本番ビルドを先に通した。変更後は計算・入力・採点・接触の28件を加えた282件、本番ビルド、確認版ビルド、確認版への本番依存の混入検査、型検査を行った。ブラウザの操作試験3件を追加し、従来の操作試験と別設定で実行する。

この作業環境ではChromiumの起動がソケット権限で失敗し、制限外での再実行は承認設定に拒否された。提供ブラウザのローカルURL接続もURLポリシーで拒否された。このためローカルでブラウザ試験が通ったとは扱わず、PRのGitHub Actionsで結果を確認する。iPhone 17 Pro Safariでの操作感・縦横表示の合否は未確認。

再現試験で、接地後の安定確認中に壁へ進入しても成功する問題と、空中から地上へ移ると予約済みの入力が消える問題を検出した。いずれも失敗を確認してから修正し、回帰試験を追加した。

## 確認版の配信と確認方法

ユーザーがこの実装PRをマージし、既存のPages配信が成功すると、本番ホームの「自由操作を試す」から開く。URLは`review/<実ソースcommit>/<Actions run id>-<attempt>/`とし、`review-info.json`と画面の情報欄にソース・ビルド・ルール・段階を表示する。同じ配信URLへ別の内容を上書きしない。旧版の保持は未実装で、次回のPages配信では古いURLが消える場合がある。

ジャンプ→パッドを横・縦・斜めへスワイプ→指を離す→逆方向へ払って勢いを抑える→足から着地、を試す。「一緒／犬／人」は回す対象で、技を選ぶボタンではない。初期速度は半分で、1倍へ切り替えられる。停止中と画面を離れた間は進めない。画面サイズが変わった場合は指の入力を閉じて停止し、再開後は新たに触り直す。

この確認版はメモリーのみを使い、保存・送信・公開順位・再送キューを初期化しない。本番の`rules-1`は従来の入口を維持する。
