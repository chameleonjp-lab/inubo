# イヌボー 自由操作のスコア表

通常の公園、練習広場、操作確認版では、跳び上がってから接地するまでに実際に回った量と方向で技名と点数が決まります。指を離した後の回転も含みます。寝た姿勢や逆さのまま接地しても、角度による失敗・減点はありません。空中の感度と回転速度の上限は、最初の調整前の5倍です（直前の版に対して1.25倍）。

## 対象と方向

| 操作対象 | 技名に入る表記 | 得点の扱い |
| --- | --- | --- |
| 犬 | 犬の | 犬が実際に回った方向と量を数える |
| 人 | 人の | 人が実際に回った方向と量を数える |
| 一緒 | 犬と人の | 犬と人のうち、回転量が多い側の回転数を使う。共通で同じ回転をしても点数は倍にならない |

犬と人を別々に操作し、両方で半回転以上の方向があれば「犬と人の」と表示します。共通操作と個別操作の回転が重なると、その時点で足し合わせた実際の回転を数えます。反対向きの勢いが同時に打ち消し合った分は回転に含みません。

| 踏切時の進行方向に対する回り方 | 技名に入る動き |
| --- | --- |
| 前を持ち上げ、後ろに宙返り | バックフリップ |
| 前を下げ、前に宙返り | フロントフリップ |
| 上下の軸を中心に左へ旋回 | 左スピン |
| 上下の軸を中心に右へ旋回 | 右スピン |
| 進行方向を軸に左へ横転 | 左バレルロール |
| 進行方向を軸に右へ横転 | 右バレルロール |

斜めの回転は、その瞬間に最も強い軸と方向に角度をまとめます。方向ごとの積み上げが180度に達すると技になります。同じ方向へ何度か分けて回した角度も合計します。半回転に達していない方向は、回転数にも組み合わせの得点にも入りません。名前には回転が多い方から最大2方向を表示し、3方向以上が成立したら「コンボ」を加えます。

## 滞空時間と上限

- 回転速度は共通・犬・人の各入力で毎秒3,600度までです。共通の回転と個別の回転が同じ向きに重なれば、1体の理論上限は毎秒7,200度です。0.8秒の例では16回転です。
- 満点は1,000点です。どちらか一方の採点対象の回転量が、そのジャンプの理論上限まであと180度以内なら満点になります。滞空時間が違うジャンプでは、その時間から上限を求め直します。
- 満点条件に届かなかったときは、採点対象の角度を半回転単位で切り下げ、その角度が理論上限に占める割合に980を掛けます。成立した方向が2種類なら8％、3種類以上なら16％を加え、小数点以下を切り捨てて1〜999点に収めます。回転数に使う角度は片方の体から取り、方向の種類は両方で数えます。
- 公園で走行の点数に加わるのは、着地した採点区間ごとに最初に成立した技です。走行全体のトリック点には既存の5,000点上限が適用されます。壁への衝突や着地前のゴールで飛行が終わった場合は、その空中技の点は付きません。操作確認版では壁やレールへの衝突でその試行が終わります。
