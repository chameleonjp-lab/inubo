### 技データと判定の入出力

`TRICK_LAB_LESSONS` は技番号を文字列 `01`〜`38` として固定する。各 `LabLesson` は `id`、日英の名称、難度、練習地形の `fixtureIds`、開始時の構え、準備・踏切または進入・空中または接触・保持または脱出・着地または復帰の姿勢、許す操作、成功に必要な条件、代表失敗、地形ごとの手本の入力列を持つ。§4の行が各定義の受入条件になる。地形寸法・許容値は共通定義へ置き、レッスンには変える値だけを書く。資料にない角度・時間・摩擦は試作値として練習内だけで使う。

- `createLabAttempt({ attemptId, lessonId, fixtureId, stance, dogId }): LabState` は開始姿勢・地形・入力待ちを作る。`advanceLab(state, untilUs, inputs): LabUpdate` は次の状態と時刻付きのイベントを返す。時刻は整数マイクロ秒、刻みは既存の `TICK_US` の5ミリ秒。`LabInput` は `{ attemptId, atUs, seq, action }` とし、`action` は下表の操作か走行開始とする。適用済みの組は捨てる。画面からの入力時刻はイベントの時刻を試行開始・一時停止・速度から換算し、手本の線・ボタンと同じ練習時計に合わせる。0.5倍で発生する端数は次の刻みに持ち越す。同じ練習時刻の入力列を使った試行は、描画の間隔や速度設定にかかわらず同じ結果になる。
- `LabState` に準備・進入・踏切・空中・支持・脱出・着地後・完了を持つ。着地後に前後の支えと走行を確認し、成功または失敗で一度だけ閉じる。落下、衝突、範囲外、制限時間で理由を残す。進入から8秒を試作の上限とし、停止画面の時間は含めない。再試行・技変更は別の `attemptId` を発行し、古い入力と接触を捨てる。手本も別の状態を使う。`LabOutcome` は成功・理由付き失敗・中止を区別する。
- 回転は犬と人それぞれの水平回転、裏返り・横転、前後の傾きを分けて持つ。各軸に向き、符号付きの累積角、逆向きに戻った量、回転速度、表示姿勢を持つ。最終方位は表示と着地面への整列に使い、回った回数は累積角で確かめる。板役の前後と人の前足・後足は踏切時の構えで別々に識別する。
- 接触の記録には `atUs`、`obstacleId`、`surfaceId`、部位、接触面（上・横・地面）、接触と荷重支持それぞれの開始・終了、接触時の位置・法線・速度を持つ。犬の足先が地面に触れること、人が犬の背に足を置くこと、前後の手でベルトを保持することを別々に記録する。接触計算には地形と姿勢を渡し、技の一致は接触履歴がそろってから確認する。

### 指で操作する流れ

技を選んだら地形、手本、五つの動作を表示する。必要な準備操作だけを見せ、選択肢は中立から始める。手本の設定は別の試行だけに反映する。再試行時は前回の準備操作を再利用できるが、技を変更したら中立に戻る。構え、進入側、犬・人の回転、前後の荷重、手と持ち手を記録する。「走り出す」で進入が始まり、位置・回転・接触の結果が条件を満たした場合に成功を表示する。25は縁で静止した状態から始まり、前荷重で降り始める。

| 操作 | 計算へ渡す内容 | 対象 |
| --- | --- | --- |
| 左右・ジャンプ | 左右へのスワイプと「左」「右」は `aim`（横の目標を動かす）、上へのスワイプと「跳ぶ」は `pop`（踏切）を送る。同じ命令には同じ動きと判定を使う。画面の短辺で軌跡を正規化し、試作は短辺の10%の横払いで0.4 mの移動。 | 進入、平地のジャンプ、レールへの寄せ |
| 回転と先端の傾きを準備する | `setup` で犬の水平回転（0°、両方向45°・90°・180°・360°）、犬の裏返り（なし・キック・ヒール）、人の水平回転（0°、両方向90°・180°）、犬の先端の傾き（上・水平・下）、脱出の動き（直進・姿勢を戻す・そのまま後退・両方向へ半回転）を選ぶ。傾きは荷重から独立させる。踏切、縁への進入、脱出開始で対応する軸が動く。 | 空中回転、斜めのレール滑走、ランプの半回転 |
| 前・中央・後へ荷重する | `load` で姿勢と足先の高さを変える。次の選択まで荷重を保つ。指定部位が実際に地面や障害物に触れるかを計算する。 | マニュアル、レール、ストール、ドロップイン |
| 足を戻す、つかむ・はなす、前足を着く | 「足を戻す」で `catch`、「前足を着く」で `plant` を送り、足が所定の位置や路面に届いた時に接触が成立する。「つかむ」で `grab` を送り、実際に持ち手に届くと同じ位置のボタンが「はなす」に変わる。もう一度押すと `release` を送る。 | フリップ、グラブ、ボンレス、ノーコンプライ |
| 止める、抜ける | `brake` は接線方向を減速する。 `exit` は準備した動きで縁から抜ける操作を始める。前後パッドを浮かす、半回転する、支持を失う、路面へ復帰する時刻をそれぞれ記録する。 | 縁での停止、レールとランプからの復帰 |

親指1本で順に操作できるよう、構えや回転軸、どちらの手でどこをつかむかは停止中に選ぶ。手を伸ばしている間は再タップを受け付けず、届かなければ「つかむ」に戻して理由を表示する。持ち手に届いた後は指を離しても保持でき、同じボタンの「はなす」を押すまで、前足を着くなどの別の操作を順に行える。空中でつかむ技では着地前に離す。ボンレスでは地上でつかんでから前足を着き、跳んで足を戻した後に離す。ボタンを押した時刻と実際に手が届いた時刻を分け、保持時間と着地の判定は§3の条件を使う。

つかむ・はなすボタンは、表示が変わっても位置と大きさを保つ。やり直しと技の変更では「つかむ」へ戻し、一時停止から同じ試行に戻るときは実際の保持状態に表示を合わせる。標準は練習時計を半速とし、通常速度も選べる。「お手本を見る」は画面と同じ入力変換を使って、座標列とボタンの操作を別の試行へ送る。手本の線・ボタンの強調・犬と人の動きは同じ練習時計で進める。ガイドを出してもプレイヤーの入力や結果を補正しない。

## 3. 動きと地形の判定

### 構えと回転

地形の前方接線を `+s`、その右側を `+x`、上を `+y` とする。左足前の試行で、通常方向に滑るときのつま先側を `+x` にそろえ、右足前は左右を鏡に映した配置とする。障害物の側は踏切前の足元から障害物までの向きをつま先方向に投影して決め、つま先側をフロントサイド（FS）、かかと側をバックサイド（BS）とする。回転のFSとBSは、回り始めにつま先側とかかと側のどちらが進行方向を向くかで決める。計算の基準にする速度の向き・つま先の向き・障害物の側を進入時に保存し、縁で止まる技もその基準から回転方向を求める。反転した出口の速度を使って符号を付け直す処理は入れない。

前足・後足、前手・後手、犬の前端・後端は開始時にそれぞれ決める。逆向きに滑るフェイキーは犬の前を向く方向と実際に進む方向を別に持つ。通常とフェイキーの成功例を実装する。スイッチとノーリーは、通常の足の左右を鏡に映す操作や通常の踏切と混同しないようにデータ上区別し、対応する技を一覧に増やす場合は別の要件にする。[回転と構えの用語](https://www.nbcolympics.com/news/skateboarding-101-olympic-terminology-and-glossary)

犬の独立回転と人の回転は同じ基準座標で積分する。犬だけが回る場合も人の肩と腰はその場の向きを保つ。犬と人が両方回る場合は各目標を独立に進める。表示用の向きとは別に、回り始めからの角度を保持する。犬の長軸の裏返りと、先端を上げ下げする傾きも別の軸にする。

足を戻せる時点と、予定の回転が完了する時点を分ける。02〜04・07〜11では、犬だけが回る動きを終えて足を戻す。12では、犬と人の水平回転の差が約180°になった段階で受けられる。試作の例は踏切320ミリ秒後に犬BS270°・人BS90°、480ミリ秒後に犬BS360°・人BS180°。13・14は裏返りが終わり、犬と人の水平の向きがそろってから足を戻し、同方向への残りの回転を続けられる。いずれも最初の着地で各軸の最終条件を確かめる。犬と人の相対角が半回転する04・07・08・10・11・12は左右の足の割り当てを犬の前後で入れ替える。相対角が変わらない13・14・36は開始時と同じ割り当てで受ける。[ビッグスピンの回転の区別](https://www.skatedeluxe.com/blog/en/trick-tips/skateboard/flat/how-to-bs-bigspin/)

### 地形と接触

`LabFixture` の短い区間だけを計算する。高さ・幅・進入点・脱出先と接触面の向きは同じ定義から描画と計算に渡す。試作の平地速度は3.5 m/s、重力は既存の `GRAVITY`、平地の踏切は `JUMP_VY` を初期値にする。試作の地形は次のとおり。各技は少なくとも1つの配置で操作でき、表に挙げた地形の組み合わせは技の一覧を増やさず選べるようにする。

| 配置 | 最初に作る形と進入条件 |
| --- | --- |
| 平地・緩い坂 | 約12 mの直線。坂は15%の下りを初期値とし、荷重技と着地の面に使う。 |
| 低い段差・階段・ギャップ | 階段は高さ0.20 mの踏み面を3段設け、下に平らな着地帯を設ける。ギャップの試作幅は1.20 m。開口部に着地面を作らず、手前0.4 mから0.1 mの間を最初の踏切の目安にする。落下距離と滞空時間は別に測る。 |
| 踏切台 | 長さ4.0 m、上端0.60 m。踏切台の上端で跳ぶときの速度は既存の `KICKER_VY` を初期値にする。 |
| 縁石・レッジ・レール | 高さ0.35 mの縁と、高さ0.50 m・長さ3.0 mのレールを用意し、脇と終端に路面を確保する。レールの半幅は `RAIL_HALF_WIDTH` を試作値に使う。左・右から進入できるようにし、手すりの下降形は上面と脱出先の高さを分ける。 |
| 曲面ランプ | 半径2.4 m・上端70°の円弧に上端の縁を付ける。横に続く縁と、上り下りの曲線の方向を別に持つ。 |

犬側の接触点は前足組・後足組、前後の練習用パッド、前端・後端・中央の裏パッド。人側は前後の足先と手。板の「ノーズ／テール」はベルトの前端／後端を指す。前後の金具と板裏は、支持点の高さと位置を別々に持たせる。手用の前端・後端・つま先側・かかと側は、背の上に設ける別の持ち手とする。部位の座標は姿勢と共通の接触点定義から求め、犬種の体型で当たり判定が変わらないようにする。

`solveLabPose(state): LabPose` は犬と人の独立した姿勢、人の腰、前後の肘・膝・手先・足先、犬側の各支持点と持ち手の座標を返す。練習用の人モデルには腕と脚をそれぞれ2節で動かす部品を使い、立位から膝を曲げ、35・36の踏切前だけ腰を横へ動かして片足を届かせる。手足の長さと曲がる範囲内で目標に届いた時だけ接触を認める。犬の足を畳む動作も、パッドが縁を支える位置に合わせる。判定と描画の両方がこの座標を使い、犬種ごとの表示用取付位置を調整する。

`sampleLabSurface(fixture, s, x): LabSurface | null` が面ID、高さ、法線、接線を返す。`sweepLabContacts(fixture, before, after): LabContact[]` が、障害物の境界で移動区間を分け、部位ごとの上面・側面への最初の接触を刻みの途中まで調べる。接触は、触れるだけのものと荷重を受けるものを分ける。縁に乗るには上面へ下りる方向の接触を必要とし、先に側面へ当たる場合や犬の体・支持に使わない足が地形を突き抜ける場合は失敗とする。上面へ届く前に各パッドが障害物の幅を越え、進入側と反対の境界まで出た時刻を、障害物ID付きで記録する。姿勢で接触点が動くため、刻みの両端が離れている場合でも途中の横切りを調べる。

曲面ランプは底から上端までの弧の長さ `q` と、上りを正とした速度を持つ。角度を `a = q / 2.4` とし、進入方向の水平位置を `2.4 × sin(a)`、高さを `2.4 × (1 − cos(a))` とする。上りの初速は8 m/s、重力で自然に減速し、止める操作でさらに減速できる。通常の勢いのままでは縁で静止しないため、上り下りの速さと縁に沿う速さの両方を計算する。25は上端に後端裏が乗った状態を初期配置とする。26〜30は上端の手前で減速する入力列を作り、31は短い跳躍で縁へ戻れる踏切域・速度を別に定義する。上端で待機、空中から縁へ接触、曲面へ下りる区間は同じ地形の座標を使う。上りと下りで犬・人の向きと速度を分け、速度だけが反転する技と、姿勢を回して下る技を区別する。

31の配置では、中央裏の支持点が上端の水平1.70 m手前、円弧の高さ約0.065 mで踏み切る入力から試す。上り方向の水平速度2.83 m/s、上向きの速度6.72 m/s、重力14 m/s²とすると、中央裏は約0.60秒後に上面へ下降する。犬と人を0.48秒で回し、後パッドが中央から0.35 m、半径0.03 m、縁の半幅0.06 mの場合、後パッド全体は約0.51秒で縁を越える見込みになる。実際の姿勢を入れたあと、踏切域の手前・中央・奥を試し、回転完了→越境→支持の順で成立する範囲を画面の目印にする。

同時刻の処理は、衝突・転倒 → そこまで継続した支持・滑走・保持時間の集計 → 接触の開始・終了 → 成否の確定 → その時刻の入力の順とする。ちょうど1.00 mで縁が終わる例と、ちょうど0.50秒で片側支持から復帰する例は、閾値に達したものとして扱う。同時刻に壁へぶつかれば衝突を優先する。「足を戻す」「離す」「抜ける」が最初の着地と同時に届いても、前の区間で成立したことにはしない。失敗は `wrongRotation`、`wrongSupport`、`wrongOrder`、`earlyRelease`、`collision`、`unstableLanding`、`timeout` に分け、画面では直すべき動作を短く伝える。初期値の調整は練習内に閉じ、変更前後の成功・失敗例と理由を残す。
